How do I get my Claude export?
  1. Request an export

    On the Claude website, open Settings → Privacy → Export data and submit the request.

  2. Open the email

    When the export is ready, open Claude’s email and follow the download link. Sign in to Claude if prompted.

  3. Download your files

    Save the conversation ZIP to your device. If Memory is provided separately, download its ZIP too; convert each file here in turn. A conversations.json file also works.

  4. Choose a file below

    Choose the downloaded ZIP or JSON below, select conversations, and export as Markdown or PDF. You do not need to unzip it first.

The email link expires after 24 hours; request a new export if it expires. Do not share the link or upload the email itself.
